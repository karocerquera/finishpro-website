# Finish Pro Painting — website

Modern landing page for [Finish Pro Painting LLC](https://finishpro-painting.com) (Naples, FL).

## Contents
- `index.html` — single-page site (EN/ES toggle, WhatsApp CTA, before/after slider)
- `assets/` — photos used on the page

## Local preview
Open with any static server from this folder, e.g. `python3 -m http.server 8766`

## Replit
Import this GitHub repo as a static site; keep `index.html` at the project root with the `assets/` folder beside it.
